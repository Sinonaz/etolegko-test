# download-speed

Консольный скрипт на Node.js: последовательно делает 10 запросов к указанному URL, считает среднее время ответа, общий объём скачанных данных и скорость в кбит/с.

## Требования

- Node.js 18+ (используется встроенный `fetch`)

## Запуск

```bash
node download-speed.js <url>
```

Пример:

```bash
node download-speed.js https://example.com/image.jpg
```

## Что выводит

Для каждого запроса — успех или ошибка. В конце:

- число успешных / всего запросов;
- среднее время успешного запроса;
- суммарный объём скачанных данных;
- скорость скачивания в **кбит/с**.

Неудачные запросы пропускаются и в метрики не входят. Если все 10 упали, скрипт завершится с кодом `1`.
